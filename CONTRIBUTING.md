# Contributing to ASDLC (AI-SDLC)

Thank you for your interest in contributing to ASDLC!
We welcome pull requests, issue reports, and suggestions for expanding The Meisters Council and agent capabilities.

## Development Workflow
1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Adhere to the **5-Stage Document-Driven Lifecycle** defined in `.agents/skills/dev-change-lifecycle/`.
3. Verify changes using `asdlc status` and run test suites:
   ```bash
   pytest tests/
   ```
4. Commit your changes with clear messages and submit a Pull Request.

## Charter Compliance
All contributions must comply with the [Meisters Review Charter](docs/charter/MEISTERS_CHARTER.md).
